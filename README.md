## My process

### Built with

- Semantic HTML5 markup
- SCSS/Sass
- Flexbox
- CSS Media Queries
- Responsive images using `<picture>` and `<source>`
- npm and Sass CLI

### What I learned

This project helped me practice writing SCSS and building a responsive layout from scratch.

I learned how to use Sass variables and nesting to organize my styles and practiced using the <picture> element to provide different images depending on the screen size:

Another area I practiced was responsive image sizing using properties such as width, height, height: auto, and object-fit.

### Continued development

I want to continue improving my SCSS skills, particularly with:

Sass mixins and functions
Partials and @use
More complex responsive layouts
Writing cleaner and more maintainable SCSS
Improving my understanding of responsive image sizing

I also want to practice recreating more designs from Figma and Frontend Mentor to improve my ability to translate designs into responsive websites.

Useful resources

AI Collaboration

I used ChatGPT as a learning and debugging assistant during this project.

I mainly used it to:

Understand SCSS concepts and syntax
Debug CSS and responsive layout issues
Understand the difference between CSS properties such as height: auto and height: 100%
Better understand Flexbox, media queries, and responsive images
Review my code and suggest improvements

I used AI primarily to understand why something worked or didn't work rather than simply copying the solution.
